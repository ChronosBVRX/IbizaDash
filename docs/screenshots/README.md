# Galería de pantallas

Capturas reales de las dos apps en el emulador (1280×720) con datos OBD de
demostración y el paquete offline de Morelia.

## Abrir la galería

Abre `gallery.html` en cualquier navegador:

```powershell
start docs\screenshots\gallery.html
```

Versión en Markdown para leer en GitHub: [`GALLERY.md`](GALLERY.md).

Haz clic en cualquier captura para verla a tamaño completo.

## Contenido

| Carpeta | App | Pantallas |
|---|---|---|
| `stereo/` | IbizaDash 1.6.0 | Inicio, mapa, música, radio, mi auto, diagnóstico, motor, eléctrico, fallas, consola, ajustes rápidos, conexión, ajustes y apps |
| `phone/` | IbizaCompanion 1.6.0 | Inicio, rutas, música, conexión, OTA, ajustes, módulos y sistema |

Hojas de contacto:

- `contact-sheet-stereo.png`
- `contact-sheet-phone.png`

## Notas

- El mapa usa las teselas offline de Morelia; no requiere Internet en el estéreo.
- Los datos del coche vienen del modo demo (`--ez obd_demo true`).
- La guía en ruta se envió desde el teléfono con una ruta real de TomTom.
